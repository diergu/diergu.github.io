Projetos

Sistema de Gerenciamento de Tarefas

Aplicação full stack para gerenciar tarefas: criar, definir prazo e responsável, mudar o status (pendente, em andamento ou concluída), filtrar e excluir. Backend em Spring Boot e frontend em Angular, para praticar a integração entre a API REST e a SPA.

  • Java 17
  • Spring Boot
  • Angular
  • MySQL
  • Bootstrap

API de Cadastro de Clientes

API REST para cadastro de clientes, com validação de dados, tratamento de exceções e regras de unicidade para CPF e e-mail. Estudo de Spring Data JPA com PostgreSQL, com endpoints de listar, buscar, cadastrar, atualizar e remover.

  • Java 17
  • Spring Boot
  • PostgreSQL
  • JPA / Hibernate
  • Maven

Dashboard de Controle de Estoque

SPA em Angular para controlar o estoque: dashboard com indicadores (total de itens, valor em estoque e itens abaixo do mínimo), tabela com ordenação e filtro, cadastro de produtos e rotas protegidas por guard, com lazy loading.

  • Angular 17
  • Angular Material
  • TypeScript
  • json-server
